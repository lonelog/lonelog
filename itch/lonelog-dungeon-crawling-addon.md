**Dungeons remember.** The room you cleared stays cleared. The door you couldn't open is still locked. The chest you skipped is still waiting. Text will never replace a good map, but it can track what changed in each room, right alongside your story.

The **Dungeon Crawling Add-on** adds one thing to Lonelog: the Room tag. Everything else (actions, rolls, oracle questions, clocks, threads) works exactly as before.

## What it adds

- **Room tags** `[R:3|status:cleared|library]` track each room's exploration state.
- **Exits** `exits:N R2, E R3` record how rooms connect, if you want to.
- **References** `[#R:3]` point back to a room you already logged.
- **Dungeon status blocks** open each session with a snapshot of every room.

No new core symbols, and one new tag to learn.

## Built for your map

Room tags work alongside a map, not instead of one. Mark the room IDs on your graph paper and use the same IDs in your log: the two keep each other honest.

## When you need it

If the dungeon is backdrop rather than challenge, core Lonelog's location tag is enough. Reach for this add-on when rooms pile up state you need to remember between sessions.

## Requires

[Lonelog](https://lonelog.itch.io/lonelog), the core notation. Like every add-on, it's optional: use it when your game needs it.
