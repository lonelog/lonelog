**Some games don't care what's in your pack. Others make every torch, ration and arrow a decision.** This add-on is for the second kind.

The **Resource Tracking Add-on** gives Lonelog a notation layer for resources as they flow in and out of play, recorded at the moment they change, inline with the actions that cause it.

## What it adds

- **Inventory tags** `[Inv:Torch|×3]` track concrete, countable items.
- **Supply notation** `[PC:Kael|Supply d8]` covers abstract levels like Usage Dice.
- **Wealth tags** `[Wealth:Kael|Gold 45|Silver 12]` track currency and trade.
- **Resource blocks** `[RESOURCES]` … `[/RESOURCES]` snapshot everything at session boundaries.

No new core symbols.

## Track what the game tracks

If your system counts arrows, count arrows. If it uses a Usage Die, use the Usage Die. If it waves supplies away, don't invent tracking that isn't there. Your character tag keeps who you are; the inventory tag keeps what you carry.

## When you need it

If supplies are flavor, core Lonelog's `Gear:` field is enough. Use this add-on when running out of something is a real threat.

## Requires

[Lonelog](https://lonelog.itch.io/lonelog), the core notation. Like every add-on, it's optional: use it when your game needs it.
